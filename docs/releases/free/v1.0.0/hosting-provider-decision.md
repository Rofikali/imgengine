# Free v1.0.0 hosting decision — 23 November 2026

The owner selected Netlify Free for release preparation. Cloudflare Pages remains the fallback. Public launch is BLOCKED. No live plan, billing, analytics, logging, retention, TLS or served response has been verified for either account.

## Artifact fit

The local candidate from f40f3c4 contains 49 static files (342,350 bytes uncompressed), including nine prerendered routes, a root 404.html, third-party licenses and a root _headers file. The inspected tar SHA-256 is 7a6c3c85d1dcce42c20e2cf786944f09cd264aedaf15b523e8af3859e7be4429. Its source tree matches merged 71d854f. The build strips the SPA fallback. All five tools process selected images locally. Hosting serves page assets. Downloads and local image sizes do not directly consume CDN transfer. The existing CI tests Chromium desktop/mobile, Firefox and WebKit, local processing, a11y, network requests, privacy and static routes against a local test server. All 12 merged-main jobs passed. [Main CI](https://github.com/Rofikali/imgengine/actions/runs/45020007920)

The inspected header file sets CSP with self-hosted scripts and two inline-script hashes, style unsafe-inline, blob allowances for local operations, nosniff, frame denial, no-referrer, restricted permissions, COOP, CORP and draft noindex. HSTS requires a live hostname check. Disable any host HTML rewriting, injected analytics or scripts that could invalidate CSP. Verify unknown URLs and /api/render return HTTP 404 with the expected headers and body. Avoid catch-all rewrites to index.html.
